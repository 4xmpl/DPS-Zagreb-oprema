# DPS Zagreb – oprema

Evidencija posudbe ronilačke opreme kluba DPS Zagreb.

- `public/` – aplikacija (stranica)
- `netlify/functions/api.mjs` – poslužiteljski dio (podaci, PIN-ovi), već složen u jednu datoteku
- `src/api.mjs` – izvorni kod poslužiteljskog dijela

PIN-ovi se postavljaju u Netlifyju kao varijable okoline `OWNER_PIN` i `DEPUTY_PIN`.
